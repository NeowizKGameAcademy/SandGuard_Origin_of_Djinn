# 프롤로그 영상 검수 기록

- 05: 1초 간격 프레임 확인. 손·램프 형태 유지, 꺼진 문양에서 점등 과정 확인. 원본 보라색 빛이 남아 선택적 색상 보정으로 청록빛 푸른색으로 변경. 보정 전후 비교 완료.
- 02: 1초 간격 프레임 확인. 후면 대기에서 고개 돌림으로 연결. 마법의 빛 없음.
- 03: 1초 간격 프레임 확인. 석재 운반·내려놓기 동작과 마지막 돌풍 확인. 허리 램프에 약한 보라색이 미리 나타남 → 최종 편집에서 화면 아래쪽 해당 색상을 어둡고 따뜻하게 보정 완료.
- 06: 1초 간격 프레임 확인. 주둥이에서 가는 길잡이 빛이 뻗고 시선 방향으로 구도가 넓어짐. 신전은 모래 속 윤곽만 노출. 보라색 빛 → 청록빛 푸른색을 향한 선택적 보정 완료. 광선 주변의 약한 색 번짐은 남아 있다.

프레임 시트의 검은 빈칸은 샘플 프레임 수가 타일 수보다 적어서 생긴 것으로, 실제 영상의 검은 프레임이 아니다.

- 01: 원본의 유리 랜턴과 피라미드 정상 수정이 생성 결과에 남았다. 영상의 동작을 보존하는 Genjutsu 부분 수정 1건을 별도 제출했다.
- 01 수정본: 1초 간격 프레임에서 금속 램프 교체와 정상 수정 제거 확인. 청년의 앉은 자세·기대는 동작·석양·작업장 구도 유지. 선택 파일은 clips/01-corrected.mp4.
- 04: 시작부터 폭풍이 강하지만, 시야가 잠기고 몸을 낮춘 뒤 램프를 꺼내는 동작은 이어진다. 마지막은 꺼진 램프의 클로즈업으로 05와 연결 가능.
- 07: 1초 간격 프레임 확인. 초기 모래 장막 → 고정된 신전의 노출 → 정상 수정 점등 → 마지막 구도 유지. 신축 작업 장비가 제거되어 이전 작업장과 구별된다.
- 음악: 프로젝트의 `메인화면 배경음.mp3` 사용. 메타데이터 제목 `SandGuard Awakens`, Instrumental. 원본을 변경하지 않고 편집본에서만 음량을 조절한다. 첫 50초 측정 원본 -16.65 LUFS, true peak -2.46 dBTP.
