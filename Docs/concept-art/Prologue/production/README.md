# 프롤로그 — 모래가 가리킨 곳

2026-09-18 제작 기준. 사용자가 제안 사항을 채택하고 제작 진행을 요청한 버전.

완성본: [SandGuard-Prologue-v1.mp4](SandGuard-Prologue-v1.mp4). 50초, 1920×1080, 24fps. 7개 생성 영상을 편집하고 기존 게임 음악, 효과음, 색상 보정, 마지막 암전을 적용했다. 전체 파일 디코딩 검사를 통과했다.

## 확정 방향

- 최종 목표 50초, 16:9, 1920×1080. 현재 콘셉트의 스타일화된 3D 판타지 화풍 유지.
- 대사·내레이션·영상에 구운 자막 없이 환경음, 효과음, 음악으로 감정을 전달한다.
- 청년은 유적 발굴 현장에서 일하는 작업자다. 석재 운반은 신축 공사가 아니라 발굴 잔해를 치우는 작업이다.
- 작업장 피라미드는 작고 풍화된 발굴 유적이다. 정상에 수정이나 마법의 빛이 없다.
- 마지막 신전은 작업장 너머 사막에 묻혀 있던 별개의 훨씬 거대한 고대 유적이다. 작업용 비계나 인양 장치가 없다.
- 폭풍은 원인 불명의 초자연적 모래폭풍이다. 인명 피해 장면 없이 위협과 경이로움을 표현한다.
- 신전은 땅에서 솟아오르지 않는다. 이미 존재하던 건물을 가린 모래가 걷힌다.
- 청년은 같은 작업장 가장자리에서 신전을 발견한다. 장면 사이 장거리 이동을 생략한 것처럼 보이지 않게 한다.
- 마지막 신전 구도를 유지한 뒤 암전한다. 게임 플레이로의 연결과 건너뛰기 UI는 추후 Unity 적용 범위다.

## 인물·소품·공간 연속성

청년: 검은 헝클어진 머리, 옅은 수염, 붉은 낡은 스카프, 찢어진 크림색 상의, 갈색 바지, 가죽 벨트와 파우치, 붕대, 손가락이 드러난 장갑. 얼굴과 의상은 원본 1·3번 기준.

램프: 원본 5번의 낡은 청동 금속 램프. 긴 굽은 주둥이, 둥근 손잡이와 감긴 끈, 작은 체인 장식, 다이아몬드 속 별 문양. 1번의 유리 랜턴은 사용하지 않는다. 램프는 언제나 하나다. 평소 허리에 매달고, 쉴 때 옆 돌 위에 둔다. 폭풍 때 왼손으로 손잡이를 잡고 오른손으로 아래를 받쳐 몸 가까이 끌어안는다. 최종 전신 구도에서는 왼손에 내린다.

마법: 1~4번에서는 꺼져 있다. 5번 문양이 처음 켜진다. 6번 주둥이에서 가는 길잡이 빛이 한 방향으로 뻗는다. 7번 신전 정상의 수정은 같은 청록빛 푸른색으로 응답한다. 보라색 번개·굵은 공격 광선·지니는 등장하지 않는다.

공간: 1~3번 작은 작업장 유적, 4~6번 같은 작업장 가장자리. 7번은 그 너머 분지의 거대 신전을 보여준다. 태양 높이와 주황빛 석양을 유지한다. 인물 기준 바람과 스카프가 날리는 방향을 일관되게 유지하며, 카메라가 반대편으로 이동하면 화면상 방향은 바뀔 수 있다.

## 사운드

- 01~03: 옅은 사막 바람, 먼 작업 소리, 석재 마찰. 알아들을 수 있는 말은 넣지 않는다.
- 04: 바람과 모래 소리가 커지며 일상의 소리를 덮는다.
- 05: 폭풍 소리를 눌러 램프의 맑고 작은 공명을 들려준다.
- 06: 길잡이 빛에 가는 지속음. 공격 효과음으로 들리지 않게 한다.
- 07: 바람이 잦아들고 신전의 낮은 공명이 남는다.
- 생성 컷에는 독립적인 음악을 넣지 않고 한 곡의 연속된 음악을 최종 편집에서 검토한다.

## 힉스필드 제작 방식

모델 카탈로그와 실제 견적을 확인한 뒤 Seedance 2.5, omni_reference, 1080p, 16:9, 컷별 원본 이미지 참조로 시작한다. 원본은 반드시 첫 프레임으로 고정하지 않고 인물·소품·화풍·구도 참조로 사용한다. 따라서 원본의 이미 켜진 빛이나 이미 드러난 신전을 그대로 시작 화면으로 쓰지 않고, 지시문에서 장면의 초기 상태와 변화를 명시한다.

5번 램프 장면을 먼저 시험 생성하여 손·소품·마법 표현을 확인한다. 이 방법으로 초기 상태와 연속성이 확보되지 않으면 해당 컷의 시작 이미지를 따로 보완한다. 문제없는 컷까지 재생성하지 않는다.

생성 견적: 컷별 54 / 45 / 54 / 63 / 63 / 72 / 99크레딧, 총 450크레딧. 모두 같은 모델·설정의 도구 견적으로 확인했다. 견적은 실제 성공·청구 내역이 아니다. 실제 진행 상태는 generation-log.json에 기록한다.

### 실제 제작 반영

7개 장면의 영상이 생성되었다. 첫 장면은 Genjutsu 부분 수정으로 유리 랜턴을 금속 램프로 교체하고 작업장 피라미드 정상의 수정을 제거했다(추가 견적 63크레딧). 05와 07은 최초 요청이 IP 검사로 종료되었으나, 사용자의 이미지 권리 보유 확인 후 공식 안내에 따라 지시문을 간결하게 정리한 재시도에서 생성되었다. 차단된 작업은 웹에서 환급 표시를 확인했다.

최종 편집은 내려받은 영상으로 로컬에서 완료했다. 중간 영상과 편집 프로젝트 ZIP의 추가 클라우드 업로드는 자동 승인 검토에서 거부되어 수행하지 않았다. `edit.jsx`는 준비했던 Higgsedit 스크립트이며 실행된 편집 결과를 뜻하지 않는다. 실제 재현 스크립트는 `finish-prologue.py`다.

음악은 게임 프로젝트의 `Assets/8.Audio/AudioResource/메인화면 배경음.mp3`(메타데이터 제목: SandGuard Awakens)를 사용했다. 원본 음원을 변경하지 않고 편집본에서 구간별로 음량을 조절했다. 효과음은 생성 영상에 포함된 소리를 사용했다. 03의 이른 발광을 낮추고, 05~07의 마법을 푸른 계열로 보정했다. 49.0~49.8초에 암전하고 마지막 0.2초는 검은 화면을 유지한다.

검수 완료: `SandGuard-Prologue-v1.mp4`, 50초, 1920×1080, 24fps, 1,200프레임, H.264/AAC, 스테레오 48kHz, 47,280,079바이트. 전체 디코딩 오류 없음, 오디오 최대 샘플 레벨 -2.6 dBFS, 마지막 검은 화면 확인. Unity 씬 연결·자동 재생·건너뛰기 UI는 이번 영상 제작에 포함하지 않았다.

## 검수 기준

- 인물 외형과 램프 형태가 컷 안팎에서 유지되는가.
- 손가락·램프·주둥이가 늘어나거나 합쳐지지 않는가.
- 일상에서 마법이 미리 켜지지 않는가.
- 작은 작업장 피라미드와 숨겨진 거대 신전이 구별되는가.
- 램프의 각성과 신전의 공개가 결과 화면만이 아니라 과정으로 보이는가.
- 신전이 상승·변형·조립되지 않는가.
- 폭풍 속 동작은 작고 명확하며, 사람에게 가해지는 폭력 표현이 없는가.
- 음성·워터마크·문자가 생성되지 않았는가.
- 최종 파일의 길이, 해상도, 오디오 유무, 첫 프레임과 마지막 암전을 확인했는가.
