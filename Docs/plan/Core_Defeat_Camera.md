# 코어 파괴 카메라와 보스 피해량

- 보스 `Enemy_Chief.prefab`의 `ActorBridge.coreDamage`를 1000으로 설정한다. 일반 적은 기존 기반 프리팹의 10을 유지한다. 현재 Level 코어 체력이 100이므로 보스가 코어에 도착하면 즉시 패배한다.
- `GameResultScreen`이 `WaveDirector`의 Lost 상태를 받는 프레임에 `CoreDefeatCamera`를 시작한다. 파괴 충전과 폭발을 놓치지 않도록 즉시 코어 앞 구도로 전환한다.
- 코어 외형의 실제 경계를 기준으로 화면 중앙과 거리를 계산하고, 약 2.4초 동안 조금씩 다가간다. 파괴 효과가 계속 재생되도록 시간을 멈추지 않고 플레이어 입력과 HUD를 막는다.
- 결과 화면은 기존 지연 시간과 파괴 카메라의 재생 시간이 모두 지난 뒤 표시한다. 결과 화면 뒤에서도 코어 구도를 유지한다. 승리 흐름은 기존대로 동작한다.
- 패배 연출 중에는 일시정지 팝업이 열리지 않는다. 재시작·메뉴 이동·컴포넌트 비활성화 시 카메라와 입력, HUD 상태를 복구한다.

`CoreDefeatCamera`를 결과 캔버스에 미리 추가하면 Inspector의 `Hold Seconds`와 `Field Of View`로 시간을 조절할 수 있다. 없으면 `GameResultScreen`이 기본 설정으로 자동 추가한다.

검증: `CoreDefeatCameraTests`가 일반 피해/치명 피해 구분, 보스 피해량, 폭발 전 카메라 도착, 파괴 연출 후 결과 화면, 중단 시 복구를 확인한다. 화면 캡처는 `Logs/CoreDefeatCaptures`에 저장된다.

2026-09-22: Unity 6000.2.8f1에서 파괴 카메라 3개, 시작 연출 4개, 기존 준비 단계 1개로 총 8개 테스트 통과. 충전·파편·결과 화면 캡처도 확인했다.
