# 경험치 입자 프리팹

`Assets/Resources/VFX/Prefabs/VFX_Experience_Mote.prefab`

금색 큐브(한 변 0.16)가 지면에서 0.35 위에 떠서 회전하고, 작은 금빛 후광이 계속 재생되는 경험치 드롭 외형이다. 자동으로 사라지지 않는다. 루트 위치를 바닥에 놓으면 되고, Play 모드에서 회전을 확인할 수 있다. Bloom이 켜져 있으면 발광이 강조된다.

현재는 외형 프리팹이다. 적 사망 시 생성, 경험치 값, 획득 범위, 플레이어를 향한 이동, 획득 시 경험치 지급 및 오브젝트 반환은 포함하지 않는다. 다음 단계에서 게임플레이 경험치 오브젝트가 이 프리팹을 자식으로 가지고 수명을 관리하도록 연결한다. 장식용 ParticleSystem의 입자 개수는 경험치 값이 아니다.

기존 `VFX_Enemy_Death`의 Ember는 짧게 재생되는 장식 파티클이며 실제 경험치 드롭이 아니다. 경험치 드롭 연결 시 두 금색 연출이 겹치는지도 확인한다.

재생성 메뉴: `DesertTower > VFX > Build Experience Mote`. `Build All`에도 포함했다. 기존 마나탄 프리팹의 Core/Glow만 재사용하고, 발사 섬광·궤적·라이트를 제거한 뒤 크기·색·회전 속도를 변경한다. 생성 규칙은 `Assets/Resources/VFX/Editor/ExperienceMoteBuilder.cs`에서 수정한다.

확인: 프리팹 내부 참조의 누락 여부를 정적 검사했고, Unity Editor 로그에서 프리팹과 머티리얼의 임포트 완료를 확인했다. 실제 화면 재생은 아직 확인하지 않았다.
