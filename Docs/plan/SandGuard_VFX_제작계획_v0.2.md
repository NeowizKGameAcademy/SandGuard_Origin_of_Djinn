## 1. 화려함은 어디서 나오는가

파티클 개수가 아니라 아래 다섯 가지가 화려함의 대부분을 만든다. 이걸 먼저 세팅하지 않으면 파티클을 아무리 늘려도 밋밋하다.

| 요소 | 효과 | 세팅 비용 |
|---|---|---|
| **Bloom (URP Volume)** | 이미시브 큐브가 실제로 빛난다. 틸 마나·주황 화염이 번진다 | 10분, 1회 |
| **흰색 플래시 프레임** | 착탄 순간 0.05s 흰색 큐브·스프라이트가 화면에 펀치를 준다 | 이펙트당 2분 |
| **카메라 셰이크 + 히트스톱** | 타격감. 폭발·보스 공격에 0.05~0.12s 타임스케일 정지 | 스크립트 1회, 30분 |
| **충격파 링** | 바닥에 퍼지는 링 메시 하나가 이펙트 크기를 3배로 느끼게 한다 | Shader Graph 1회, 40분 |
| **잔광·잔해** | 메인 폭발 뒤 0.5~1.5s 남는 불씨·먼지·낙하 큐브 | 이펙트당 5분 |

## 3. 표준 레이어 구조 (모든 임팩트형 이펙트)

임팩트형 이펙트(피격·폭발·소환·건설)는 아래 5겹을 자식 파티클 시스템으로 갖는 프리팹 1개다. 베이스 프리팹 `VFX_Impact_Base`를 만들고 복제해서 색·크기만 바꾼다.

1. **Flash** — 흰색 스프라이트 1장, 0.05s, 크기 2→0. 이미시브 6.
2. **Core** — 주색 큐브 3~5개, 0.15s, 중심에서 커졌다 사라짐.
3. **Shockwave** — 바닥 링 메시 1개(Shader Graph, 알파 링 확장), 0.3s.
4. **Debris** — 큐브 15~30개, 방사 + 중력, 0.6~1.0s, 회전.
5. **Ember/Afterglow** — 작은 스프라이트 10개, 느리게 상승, 1.5s, 알파 페이드 허용.
+ 라이트 1개, + 카메라 셰이크·히트스톱 호출(스크립트 이벤트).

루프형(충전·소환진·화염)은 **Base Loop(상승 큐브) + Glow(스프라이트 펄스) + Sparks(간헐 Burst)** 3겹.

## 5. 공통 세팅 (D3~D4에 먼저 끝낼 것)

1. **URP Volume**: Bloom(Threshold 0.9, Intensity 0.8, Scatter 0.6), Vignette(빨강, 기본 0, 스크립트로 가중치 제어), Color Adjustments(Post Exposure 0, Saturation +10). 카메라 HDR 켜기.
2. **Shader Graph 4종**: `SG_Shockwave_Ring`(알파 링 확장), `SG_Dissolve`(노이즈 클립 + 틸/금 엣지), `SG_Beam_Scroll`(빛기둥·빔 UV 스크롤), `SG_HitFlash`(캐릭터 이미시브 램프, 스킨드 7종 공유).
3. **피드백 스크립트**: `CameraShake`(강도 3단계), `HitStop`(타임스케일 0 → 복귀), `ScreenVignette`. 이펙트 프리팹에서 이벤트로 호출.
4. **베이스 프리팹 3종**: `VFX_Impact_Base`(5겹), `VFX_Loop_Base`(3겹), `VFX_Projectile_Base`(코어+글로우+트레일+라이트).
5. **텍스처 5장**: 사각 소프트 글로우, 픽셀 링, 룬 문양 2종, 화염 스프라이트(4프레임 플립북). 전부 128~256px, 픽셀 아트로 직접 그리거나 이미지 생성기로 뽑고 포스터라이즈.
6. **오브젝트 풀 + `VfxService.Play(VfxId, pos, rot, parent)`**.

## 8. 성능 가드

- 동시 파티클 3,000개 이하, Bloom은 Quality High에서만 Scatter 0.6, Low에서는 0.4.
- 포인트 라이트 동시 8개 이하(URP Forward+ 기준 넉넉), 라이트 없는 버전을 Quality Low용으로 별도 프리팹.
