# 타워 하수인 지면 보정 (2026-09-22)

## 타워 수정 규칙
- 사용자 요청: 앞으로 타워 관련 코드를 교체할 때 기존 코드를 삭제하지 않고 주석으로 보존하고 변경 이유를 설명한다.

## 변경
- 스켈레톤/아누비스가 소환 지점의 Y를 유지한 채 수평 이동하여 지형에서 떠 있던 문제를 수정한다.
- 소환 직후 및 LateUpdate에서 아래 방향으로 바닥을 검사하여 루트 높이를 맞춘다. 기존 추적/귀환의 수평 이동과 공격 거리 계산은 유지한다.
- 자기 콜라이더, 전투 대상 콜라이더, 트리거, 급경사 측면은 바닥 후보에서 제외한다.
- 바닥이 검출되지 않으면 기존 위치를 유지한다. 이번 변경은 중력/절벽 낙하나 길찾기를 추가하지 않는다.
- 기존 소환 위치 대입문은 SummonManager에 주석으로 보존했다.

## 검증
- MinionGroundingTests: 높은 소환점에서 지면 정렬, 자기 콜라이더/트리거 무시, 경사면 왕복, 바닥 미검출 시 위치 유지.
- Unity 6000.2.8f1 EditMode 실행 결과: 3개 통과, 실패 0개. 스크립트 컴파일 성공.
- 실제 게임 씬의 애니메이션/발 접촉은 화면으로 확인하지 않았다.
