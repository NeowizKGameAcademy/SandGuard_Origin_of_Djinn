# 아군 하수인: 높이 판정, 플랫폼 복귀, 공격 타이밍

## 요청과 수정 원칙
- 높이 차이가 큰 적을 수평 거리만으로 공격하는 것은 버그다.
- 플랫폼 이탈 시 걸어서 복귀를 시도하고, 불가능하면 원래 소환 위치로 이동한다.
- 타워 관련 기존 코드는 교체 위치에 주석으로 보존하고 이유를 설명한다.

## 동작
- 스켈레톤과 아누비스의 기본 공격은 발 위치의 수직 차이와 기존 수평 사거리를 모두 검사한다. 가슴/방패 조준점 높이가 큰 적도 같은 지면에 있으면 공격할 수 있다.
- 공격 불가능한 높이의 적은 하수인 대상 선택에서 제외한다. 타격 시점에 대상 생존 여부, 수평 사거리, 높이를 재검사한다.
- 트리거 프레임의 즉시 피해를 없애고 실제 Animator 상태의 정규화 진행률에서 한 번 타격한다. 공격 상태가 끝나기 전에는 재공격 트리거를 쌓지 않는다. 사망/비활성화/강제 복귀 시 대기 중 피해를 취소한다.
- 실제 컨트롤러 연결: Skeleton Attack → Standing Melee Attack Downward, Anubis Attack → Mutant Swiping, Anubis UseSkill → Standing Melee Attack Backhand.
- 아누비스 넉백도 스킬 타격 시점에 실행하고, 다른 층/아군/동일 대상의 중복 콜라이더는 제외한다.
- 소환점보다 낮아지거나 타워의 수평 복귀 범위를 벗어나거나 바닥/가까운 NavMesh를 잃으면 공격보다 복귀를 우선한다.
- 완전한 NavMesh 경로가 있으면 이를 따라 걷는다. 경로 없음/이동 정체 또는 최대 복귀 시간이 지나면 저장한 소환점 높이로 복귀한다. NavMesh가 없는 씬에서는 대기 후 위치 복귀가 적용된다.

## Inspector 조정값 (SkeletonMovement / AnubisController)
| 항목 | 초기값 | 의미 |
|---|---:|---|
| Max Attack Height | 1.5m | 허용하는 발 위치 높이 차이 |
| Attack Impact Time | 0.45 | 실제 공격 애니메이션의 45% 지점에서 타격 |
| Skill Impact Time | 0.45 | 아누비스 스킬의 타격 지점 |
| Return Settings / Radius | 0 | 0이면 소유 타워의 DetectRange를 사용; 양수이면 별도 월드 거리 |
| Return Settings / Fall Height | 2m | 소환 위치보다 낮아졌을 때 복귀를 시작하는 높이 차이 |
| Return Settings / Stuck Timeout | 2초 | 이동 정체/경로 없음 후 위치 복귀까지의 시간 |
| Return Settings / Max Walk Time | 10초 | 걸어서 복귀를 시도하는 최대 시간 |

복귀 범위와 타격 진행률은 임시 기본값이다. 타격 진행률은 재생 속도 변경을 따라가지만, 모델의 손/무기 접촉 프레임에 대한 시각적인 미세 조정은 별도 확인이 필요하다.

## 검증
- MinionCombatRecoveryTests: 수직/수평 사거리 재검사, 파괴된 대상, 실제 프리팹 애니메이터의 단일 타격 및 재생 속도 변화, 공격 취소, 실제 스켈레톤 피해 호출, NavMesh 보행 복귀, 경로 없음과 새 장애물에 막혔을 때 복귀.
- MinionGroundingTests: 기존 지면 보정 회귀 테스트.
- Unity 6000.2.8f1 EditMode 결과: 총 15개 통과, 실패 0개. 스크립트 컴파일 성공.
