# 게임 시작 맵 소개

`Assets/1.Scene/Level.unity`의 **Level Opening Cinematic** 오브젝트가 씬 시작 시 한 번 재생한다. 메뉴에서 시작하거나 레벨을 다시 시작할 때마다 재생하며, 스토리 영상의 시청 기록과는 별개다.

| 순서 | 장면 | 시간 |
| --- | --- | --- |
| 1 | 신전 전체 전경 | 1.7초 |
| 2 | 서남쪽 적 진입로 | 1.2초 |
| 3 | 동북쪽 적 진입로 | 1.2초 |
| 4 | 정상의 코어 | 1.3초 |
| 5 | 실제 플레이어 카메라로 복귀 | 1.2초 |

- 각 장면은 두 위치 사이를 천천히 이동한다. 장면 전환에는 짧은 암전을 사용한다.
- 클릭 / Space / 게임패드 아래쪽 버튼으로 건너뛴다. 0.45초 동안 플레이 시점으로 복귀하며, 건너뛰기 버튼을 놓은 뒤 조작을 재개한다.
- `GameManager.RequestPause`를 사용해 적 생성, 준비 시간, 플레이어 조작을 멈춘다. 카메라와 UI는 `unscaledDeltaTime`으로 재생한다.
- 연출 중 화면 HUD를 숨기고 입력을 가린다. 종료·컴포넌트 비활성화·씬 해제 시 HUD, 카메라, 커서와 자신이 요청한 일시정지만 복구한다.
- `PlayerCameraRig`는 실제 카메라 위치를 계속 계산한다. 소개 컴포넌트가 뒤쪽 `LateUpdate`에서 최종 화면만 덮어쓰므로 원래 카메라 방향과 충돌 보정을 그대로 이어받는다.

Inspector의 `Shots`에서 각 장면의 위치(`From`, `To`), 주시점(`Look At`), 시야각, 길이와 문구를 조정할 수 있다. `Play On Start`를 끄면 해당 씬의 소개를 생략한다. `SandGuard > Build Level Opening Cinematic`은 현재 맵 마커를 기준으로 기본 구도를 다시 생성해 Level 씬에 저장한다.

검증 코드는 `LevelOpeningCinematicTests`에 있다. 자동 종료, Space와 클릭 건너뛰기, 다른 일시정지 요청 유지, 중단 시 복구, 실제 Level 씬의 준비 시간 정지와 조작 복귀를 확인한다. 실제 씬 테스트의 화면 캡처는 `Logs/OpeningCaptures`에 저장한다.

2026-09-22 검증: Unity 6000.2.8f1에서 소개 테스트 4개와 기존 준비 단계·적 스폰 테스트 2개 통과. 네 장면을 직접 렌더링해 구도를 확인했으며, 진입로 카메라는 불투명한 모래폭풍 안쪽에 배치했다. 첫 프레임의 로딩 시간과 긴 프레임 지연으로 장면이 건너뛰어지지 않도록 재생 시간 증가량을 제한한다.
