# 적 장비 모델 v1

Blender로 직접 제작한 게임용 장비 7종입니다. AI 3D 생성은 사용하지 않았습니다. 기존 이미지의 색과 실루엣을 단순화한 로우폴리 모델이며, 이미지 속 모든 작은 복셀을 개별 정육면체로 재현한 모델은 아닙니다.

## 파일

- `EnemyEquipment.blend`: 편집용 원본. 컬렉션별로 장비가 나뉘어 있으며 한눈에 보도록 배치되어 있습니다. 카메라·조명·글자는 미리보기 전용입니다.
- `Exports/*.fbx`: 장착 기준점 원점의 개별 Unity 교환 모델.
- `Exports/*.glb`: 색상 텍스처를 내장한 개별 모델. 망토 GLB는 애니메이션을 포함합니다.
- `Exports/EquipmentPalette.png`: 공용 128×128 팔레트. FBX와 함께 보관하세요. FBX 내보내기가 만든 `.fbm` 폴더에도 사본이 있습니다.
- `Previews/Equipment_Overview.png`: 실제 모델을 렌더링한 전체 미리보기.
- `Previews/ChiefCape_Fit_Front.png`, `ChiefCape_Fit_Rear.png`: 프로젝트의 우두머리 GLB에 망토를 임시 배치한 확인 이미지. 몸체는 배포용 장비 파일에 포함하지 않았습니다.
- `build_equipment.py`: 재생성용 Blender 스크립트.
- `verify_equipment.py`, `verification.json`: FBX/GLB 재임포트 검사 및 결과.

## 크기와 좌표

Blender 원본은 미터 단위이며 X=오른쪽, -Y=전면, Z=위입니다. FBX는 Y-up으로 내보냈습니다. Unity에서 모델 루트 아래의 변환까지 포함하여 실제 축을 확인한 후 장착하세요. 장비 루트 원점은 손잡이 중앙이고, 망토는 어깨 부착 기준입니다.

프로젝트의 Tripo 몸체 GLB들은 높이가 약 1 단위로 정규화되어 있습니다. 망토 피팅 렌더는 우두머리 몸체를 1.8배로 확대하여 약 1.8m로 사용했습니다. 그때 Blender 망토 루트 위치는 `(0, 0.10, 1.45)`입니다. 기존 몸체를 높이 1 단위로 쓴다면 장비도 대략 `1/1.8` 배율을 출발점으로 삼으세요. 부모의 스케일이 이미 적용되어 있다면 중복으로 축소하지 마세요.

손 본 아래에 장비 프리팹을 넣고 손잡이가 손바닥에 오도록 회전·위치·크기를 조절합니다. 손가락의 쥐는 자세, 방패를 드는 손의 방향, 양손 망치의 보조 손 IK는 캐릭터 애니메이션에 맞춰 별도로 설정해야 합니다. 방패에는 두께와 뒷면 손잡이 구조가 있습니다. 자동 콜라이더는 추가하지 않았습니다.

## 망토

12mm 두께의 닫힌 메시입니다. `CapeRoot`와 좌·중·우 4단 체인으로 총 13개 본을 가지며, 윗단은 고정하고 아래로 갈수록 부드럽게 휘도록 웨이트를 배분했습니다. 본당 가중치는 정규화되어 있습니다.

`Cape_Idle_Sway`는 24fps 기준 2초 반복 애니메이션입니다. 캐릭터 등/가슴 본 아래에 망토 전체 프리팹을 연결하면 상체를 따라가면서 독립적으로 흔들릴 수 있습니다. 천 물리 시뮬레이션과 충돌 회피 기능은 포함하지 않습니다. 달리기·공격·방어에서 몸이나 다리를 관통하지 않도록 최종 캐릭터와 함께 조정해야 합니다.

## Unity

`Assets/Enemy/Editor/EnemyEquipmentBuilder.cs`의 메뉴 `SandGuard > Enemy > Build Equipment Assets`는 `Assets/Enemy/Art/Equipment`에 FBX, URP 재질, 프리팹과 망토 Animator Controller를 만듭니다. 기존 적의 외형 프리팹이나 전투 동작에는 자동 연결하지 않습니다. 이 메뉴를 다시 실행하면 이 장비 폴더의 생성 결과를 갱신합니다.

망토는 Humanoid가 아닌 Generic 리그입니다. 공용 팔레트는 Point 필터, 압축 없음, 밉맵 없음으로 임포트합니다.

## 검증 범위

모든 FBX/GLB를 Blender에 다시 불러와 메시 수, 삼각형 수, UV, 텍스처, 스케일을 검사했습니다. 망토는 두 형식 모두 13개 본, 정규화된 웨이트, 실제 메시 변형, 반복 시작/끝 일치를 확인했습니다. GLB 임포터가 리그 표시용으로 만드는 Icosphere는 실제 장비 메시에서 제외합니다.

Unity 6000.2.8f1 배치 검증을 통과했습니다. 장비 7종의 프리팹과 URP 재질을 생성했고, Unity에서 망토 애니메이션을 샘플링하여 SkinnedMeshRenderer가 실제로 변형되는 것을 확인했습니다. 결과는 `unity-verification.txt`에 기록했습니다.

몸체에 망토를 배치한 앞·뒤 렌더도 확인했습니다. 완성된 적 캐릭터의 전투 애니메이션 연결과 충돌 검증은 아직 수행하지 않았습니다.
