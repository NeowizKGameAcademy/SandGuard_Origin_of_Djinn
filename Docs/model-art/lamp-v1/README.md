# Lamp v1

Blender에서 직접 제작한 황동 로우폴리 오일 램프입니다. Tripo를 사용하지 않았으며 Player/Unity 프로젝트 에셋은 수정하지 않았습니다.

- `Lamp.blend`: 원본과 미리보기용 카메라/조명. 무대와 조명은 내보내기에 포함되지 않습니다.
- `Lamp.fbx`: Unity로 가져올 모델. 메시 하나, 재질 6개, 장착 기준점 4개.
- `Lamp.glb`: PBR 재질을 포함한 교환/미리보기용 모델.
- `Lamp-preview.png`: Blender 렌더링.
- 약 29cm 길이, 14cm 높이. 1,416 triangles. 텍스처 파일 없이 면별 재질로 색을 표현합니다.

## 장착과 동작

루트 `Lamp_SwingPivot`은 손잡이 윗부분에 있습니다. 이 루트를 허리 소켓에 연결한 후 회전시키면 매달린 흔들림을 만들 수 있습니다. 현재 동작 스크립트나 물리 설정은 포함하지 않습니다.

`BeltAttach`: 허리 걸쇠 기준. 루트와 동일 위치.

`HandGrip`: 손으로 잡을 위치의 참고점. 캐릭터 손 포즈에 맞춰 최종 위치와 회전을 조정해야 합니다. 손 소켓에 연결한 뒤 이 점이 손과 맞도록 램프 위치를 보정합니다.

`FlameSocket`: 주둥이 끝. 불꽃 효과나 Light를 추가할 위치.

`BodyCenter`: 몸통 중심 참고점. 콜라이더/무게중심 설정에 활용할 수 있습니다.

## 재질

황동 3색, 테두리 황동, 어두운 홈, 발광 가능한 문양 재질로 구성됩니다. `Magic_Inlay_Emission`의 기본 발광은 꺼져 있습니다. 문양 발광은 제안된 선택 사항이며, 불꽃만 사용할 수도 있습니다.

FBX에서 Unity URP 재질로 자동 변환되는 결과는 아직 확인하지 않았습니다. 통합 시 URP/Lit 재질로 연결하고 금속도/거칠기를 맞추며, 문양을 빛내려면 Emission을 켭니다. 실제 주변 조명은 별도 Light가 필요합니다. Blender 미리보기 조명은 게임 모델에 포함되지 않습니다.

후속 Unity 연결 완료: `Assets/Player/Art/Lamp/Lamp.prefab`에 URP 재질과 조명을 연결했습니다. `PlayerLampEquipment`에서 허리/손 장착 전환, 제한된 흔들림, 문양 발광과 조명을 제어합니다. 캐릭터의 2K GLB 텍스처도 복원했습니다. 상세 실행 안내는 `Assets/Player/Art/README.md`를 참고하세요.
