# SandGuard 피라미드 블록아웃 v1

`SandGuard_Spiral_Blockout_v1.blend`를 Blender에서 열면 수정할 수 있습니다. 외부 텍스처 없이 재질과 카메라를 파일에 포함했습니다. Blender 5.2.1 LTS로 제작했습니다.

## 구성

- **외곽 나선형 적 경로:** 지상 진입 경사로에서 출발해 하층·중층·상층을 지나 정상 코어에 도달합니다. 각 층에서 평지 세 면을 돌고 네 번째 면의 경사로로 올라갑니다. 경사로 양끝에는 평평한 연결부가 있습니다.
- **닫힌 본체:** 본체와 길을 별도 오브젝트로 구성했습니다. 출입구, 내부 계단, 워프와 포탈은 없습니다.
- **플레이어 수직이동:** 정면과 오른쪽 면에 층별 도약·착지 지점을 표시했습니다. 청록 선은 이동 능력을 설명하는 가이드이며 시설이 아닙니다.
- **건설 슬롯 8개:** 하층 3개, 중층 3개, 상층 2개를 임시 배치했습니다. 각 슬롯은 별도 패드와 위치 오브젝트로 되어 있어 이동할 수 있습니다. 패드 크기와 배분은 검토용입니다.
- **정상 코어:** 정상 바닥, 코어 받침, 수정 모형과 목표 위치를 분리했습니다.
- **기준 인체:** 1.8m 크기의 간단한 인체를 하층에 두었습니다.

## 초기 치수

| 항목 | 값 |
|---|---:|
| 본체 최대 가로·세로 범위 | 약 45m |
| 평지 길 폭 | 약 4m |
| 층간 높이 차 | 3m |
| 하층 / 중층 / 상층 높이 | 0.6m / 3.6m / 6.6m |
| 정상 바닥 높이 | 9.6m |
| 가장 가파른 길 표면 | 약 14.58도 |
| 전체 적 동선 | 약 379.75m |
| 슬롯 패드 | 1.4m 정사각형 |
| 표시한 도약의 높이 / 수평 거리 | 3m / 약 1.28m |

모두 초기 제안값입니다. 실제 플레이어의 도약 성능과 적 속도에 맞춰 크기와 이동 시간을 조정해야 합니다. 예를 들어 속도 3m/s인 적이 저지 없이 경로 전체를 이동하면 약 127초가 걸리는 길이입니다. 3m/s는 계산 예시이며 기획 확정값이 아닙니다.

## Blender에서 수정하기

컬렉션을 목적별로 나눴습니다.

| 컬렉션 | 내용 |
|---|---|
| `01_Solid_Pyramid` | 닫힌 본체, 지상 기반 |
| `02_Enemy_Road` | 평지 9개, 층간 경사로 3개, 진입 경사로 |
| `03_Core_Platform` | 정상 바닥, 코어와 목표 위치 |
| `04_Build_Slots_8` | 슬롯 패드와 `BuildSlot_01`부터 `08`까지 위치 오브젝트 |
| `05_Player_Landing_Guides` | 도약·착지 위치와 청록 가이드 |
| `06_Route_Guides` | 주황 경로 가이드와 순서가 있는 경로 위치 21개 |
| `07_Scale_Reference` | 인체 크기 참고 |
| `08_Presentation` | 카메라, 조명, 렌더 배경 |

가이드 컬렉션을 숨기면 본체와 길의 형태만 볼 수 있습니다. `Camera_Hero`, `Camera_Top`, `Camera_Rear`를 저장했습니다. 파일 안의 `READ_ME_FIRST` 텍스트에도 간단한 설명이 있습니다.

## Unity용 파일

- `Exports/SandGuard_Spiral_Blockout_v1.fbx`: 본체·도로·코어·슬롯 메시 38개와 코어/슬롯/경로 위치 오브젝트를 포함합니다. 조명, 카메라, 인체와 가이드 선은 제외했습니다.
- `Exports/SandGuard_Spiral_Blockout_v1_layout.json`: 미터 단위의 경로·슬롯·도약 좌표입니다. Blender 좌표와 Unity 좌표를 함께 제공합니다. `exact_route_nodes_unity`는 모서리와 경사 변화 지점을 포함한 21개 경로점입니다.

FBX를 Unity로 가져온 다음 정적 바닥과 벽에 적절한 충돌체를 설정하고 이동을 확인할 수 있습니다. 경로 데이터는 참고 데이터이며 이 작업에서 적 AI나 플레이어 능력을 연결하지 않았습니다. Unity 씬과 기존 레벨 에셋도 변경하지 않았습니다.

## 확인한 범위

적 경로를 따라 516개 지점의 바닥 높이를 검사했고 누락이 없었습니다. 층간 착지 지점의 바닥도 확인했습니다. 지형 메시의 닫힌 형태, 슬롯 8개, 길의 최대 경사를 검사했습니다. 저장한 `.blend`를 다시 열고 FBX를 재수입해 메시 수와 크기 유지도 확인했습니다.

Unity에서 적의 길찾기, 실제 수직이동과 3인칭 카메라는 아직 플레이 테스트하지 않았습니다. 이 블록아웃은 그 확인을 시작할 수 있는 모델입니다.

앞·뒤·위 렌더는 `Previews` 폴더에 있습니다. 크기를 다시 생성하려면 `build_spiral_blockout.py` 상단의 `PARAMS`를 조정할 수 있습니다. 생성기를 재실행하면 이 v1 출력 파일들을 덮어쓰므로 직접 수정한 모델은 다른 이름으로 저장하세요.
