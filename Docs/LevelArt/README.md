# SandGuard 레벨 그래픽 시트

> 이 문서는 과거 v1 설명입니다. 최신안은 `README-v2.md`와 `SandGuard_Spiral_Level_Concept_v2.png`를 참고하세요. 내부 계단은 폐기했으며, 현재 기준은 외곽 나선형 경사로와 플레이어의 수직이동입니다.

캐릭터 시트처럼 레벨의 외형, 다른 방향의 모습, 내부 구조와 반복 제작할 부품을 모은 환경 콘셉트 시트입니다. 구현용 확정 도면이 아니라 시각 개발 초안입니다.

## 참고한 레벨 내용

- 원본: `../SandGuard_Origin_of_Djinn_게임기획서_v0.5_SkillTree_UI_Boss.pptx`
- 실제 슬라이드 10, LEVEL DESIGN: 입구 → 하층 → 중층 → 상층 → 코어. 3개 층에 건설 슬롯 총 8개. 플레이어는 내부 계단과 이동 스킬로 층간 재배치. 도착한 적은 정상 코어에 흡수되어 안정도 피해를 줍니다.
- 실제 슬라이드 5, PLAYER MOVEMENT: 달리기·점프·내부 계단으로 필수 경로를 이동합니다. 대시·더블 점프는 대응 시간을 줄이는 선택 경로입니다.
- 두 슬라이드의 삽화를 외형 참고로 사용했습니다. 밝은 사암, 블록형 조형, 청록 마력, 붉은 천, 불빛을 유지했습니다.

## 시각화 제안

- 층별 슬롯 수 3 / 3 / 2는 총 8개를 구체화하기 위한 제안입니다. 원문에 층별 배분은 없습니다.
- 정면·측면·단면과 모듈은 원본 외형을 해석한 디자인 제안입니다. 실제 길이, 층고, 계단 규격과 이동 시간은 확정하지 않았습니다.
- 통로 폭과 시야는 Unity 그레이박스에서 캐릭터 및 카메라 크기로 검증해야 합니다. 그림은 치수 도면이나 경로 연결을 보증하는 설계도가 아닙니다.
