# SandGuard 외곽 나선형 피라미드 · 형태 검토안 v2

최종 이미지: `SandGuard_Spiral_Level_Concept_v2.png`

## 최신 디자인 기준

사용자가 이번 대화에서 정정한 내용이 PPT와 v1의 내부 계단 설정보다 우선합니다.

- 피라미드 내부에는 진입하지 않습니다. 내부 계단, 출입구, 워프, 포탈을 제외합니다.
- 적은 외곽 나선형 길을 따라 경사로로만 정상 코어에 도달합니다.
- 플레이어는 수직이동 능력으로 인접한 층 사이를 직접 오갑니다.
- 하층·중층·상층의 세 방어 구간과 정상 코어를 유지합니다.
- 건설 슬롯 총 8개라는 기획은 유지하되, 이미지의 작은 사각 패드는 위치 예시입니다. 이 그림은 8개 슬롯의 전체 배치 도면이 아닙니다.

## 이번 외형 제안

블렌더에서 큰 덩어리와 길의 형태를 먼저 잡기 위한 조감도입니다. 길 전체가 네 면을 감싸며 조금씩 상승하는 연속 경사로 안을 표현했습니다. 평평한 전투 구간과 경사로를 나누는 방식 대신 제안한 형태이며, 구현 방식으로 확정한 것은 아닙니다.

벽체의 수평 줄눈과 길의 기울기를 구분해 상승 구조가 보이도록 했습니다. 내부는 막힌 덩어리로 두고, 청록 화살표는 플레이어의 수직이동을 표시합니다. 화살표는 시설이 아닙니다.

## 모델링에서 정할 항목

- 길 폭, 층고, 층별 후퇴 폭과 경사각은 미확정입니다.
- 수직이동의 실제 도달 높이와 착지 여유에 맞춰 층 간격을 조정합니다.
- 후면을 포함한 단일 적 경로, 지상 진입부와 마지막 코어 접속부는 3D에서 연결을 확인합니다.
- 슬롯 총 8개를 배치하면서 통행 폭과 플레이어 착지 공간을 확보합니다.
