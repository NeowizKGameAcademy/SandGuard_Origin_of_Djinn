# R01 · 프리비즈를 이용한 Seedance 2.5 촬영 시험

2026-09-23 · 본편 R01 한 컷 · 5초 · 16:9 · 1080p 요청

## 시험 목적

승인된 3D 프리비즈의 카메라 이동·가려짐·인물 동선을 유지하면서, 같은 구도로 만든 완성형 기준 이미지의 재질과 조명으로 생성할 수 있는지 확인한다. 49초 본편 전체의 생성은 이 시험에 포함하지 않는다.

## 입력

- [동작·카메라 기준 영상](R01-motion-reference.mp4): 기존 Blender R01 카메라와 배우 동작을 수정 없이 1–108프레임 재출력했다. 1280×720, 24fps, 무음. 편집용 글자는 제외했다. 원래 4.5초 뒤에 마지막 화면 0.5초를 붙여 모델의 정수 초 길이에 맞췄다.
- [시작 외형 기준](R01-look-start.png), [종료 외형 기준](R01-look-end.png): 기존 프리비즈 프레임의 구도를 바탕으로 새로 만든 영상용 이미지다. 닳은 사암, 크림색 작업복, 적갈색 스카프, 청동 램프, 투명한 푸른 마석을 적용했다. 업로드용 JPG는 1280×720이다.
- 기준 이미지 제작은 **imagegen 스킬의 내장 image_gen 도구**를 사용했다. CLI/API 대체 경로는 사용하지 않았다.
- 프롬프트: [시작 이미지](start-image-prompt.txt), [종료 이미지](end-image-prompt.txt), [영상](video-prompt.txt).

## 생성 설정과 기록

Seedance 2.5 `omni_reference`, 5초, 1080p, 16:9, high bitrate, 무음, 결과 1개. 이미지 2개는 외형 참조, 영상 1개는 이동 참조로 전달했다. 시작/끝 프레임을 강제 고정하는 방식은 아니다.

사전 견적은 **60크레딧**, 시작 전 잔액은 1,699크레딧이었다. 이미지 제작은 별도의 내장 image_gen 도구를 사용했으므로 이 Higgsfield 영상 견적에 포함되지 않는다.

작업 ID: `3f12a32c-7624-4a41-b35b-337c75562e8e`. 상세 요청은 [request.json](request.json), 제출 응답은 [generation-log.json](generation-log.json)에 저장했다.

## 평가 기준

1. 전경 기둥이 빠르게 빠지고 먼 기둥은 더 느리게 움직이는가.
2. 인물·기둥의 새로운 면과 가려짐의 변화가 보이는가.
3. 후반에 마석과 제단이 오른쪽에서 드러나는가.
4. 두 걸음과 정지, 왼손 램프의 연속성이 유지되는가.
5. 얼굴·의상·세트가 이동 중 다른 형태로 바뀌지 않는가.

참조 생성은 3D 렌더의 픽셀별 재질 교체가 아니다. 결과는 원본과 같은 시점의 프레임 및 재생 비교로 따로 판정한다.

## 출력과 판정

- [생성 결과 재생용](R01-Seedance25-Playback.mp4): 1920×1080, 24fps, 5초, H.264, 무음. 원본 HEVC 10bit 출력은 [R01-Seedance25-v1.mp4](R01-Seedance25-v1.mp4)에 보존했다. 원본 길이는 5.04초이며 재생용 파일은 끝의 여유 화면 1프레임을 제외했다.
- [원본과 생성 결과의 동시 비교 영상](R01-Previs-vs-Seedance.mp4): 왼쪽 3D 프리비즈, 오른쪽 Seedance 생성. 시간 속도 변경 없이 같은 시점으로 나란히 배치했다.
- [다섯 시점의 프레임 비교](R01-frame-comparison.jpg): 0, 1, 2, 3, 4.45초.

**1차 판정: 카메라·공간 전달은 유효하다.** 1초 부근 전경 기둥이 인물을 가리는 위치와 시점, 2초 이후 다시 드러나는 인물, 3초 부근 인물·기둥의 새로운 면, 끝에서 오른쪽에 드러나는 마석과 제단이 원본 흐름을 따른다. 기준 이미지의 의상·돌·청동·마석 질감도 이동 중 이어진다. 이 판정은 추출한 시점들의 시각적 비교에 근거하며, 카메라 좌표의 수치적 일치를 검증한 것은 아니다.

완전히 같은 렌더는 아니다. 인물의 크기·발 디딤과 마지막 프레이밍에 차이가 있고, 새로 만든 기준 이미지 자체도 원본 실루엣을 픽셀 단위로 보존하지 않는다. 보행의 무게감과 손·램프의 세부 연속성은 본편 채택 전 재생 검토 대상이다. 한 컷의 성공만으로 접촉·소멸 컷의 성공까지 보장하지 않는다.

출력 파일 전체 디코딩은 통과했다. 생성은 **1회**, 실제 잔액 변화는 **1,699 → 1,639크레딧**으로 60크레딧이다. 추가 생성이나 다른 컷 생성은 하지 않았다. 완료 응답은 [result.json](result.json)에 저장했다.
