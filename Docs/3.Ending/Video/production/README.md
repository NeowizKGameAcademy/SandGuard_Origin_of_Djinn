기준 이미지는 내장 imagegen으로 제작했다. 기존 프롤로그에서 인물과 램프의 정체성에 필요한 특징만 참고하고 구도를 새로 만들었다. 영상은 Seedance 2.5의 이미지 참조 모드, 1080p, 장면별 환경음 생성으로 만들었다. 영상 재생성 없이 첫 7개 결과를 사용했다.

## 대사와 소리

실제 한국어 대사는 한 문장이다.

> 이 사막에 살아가는 모두에게 자유를 돌려줘.

원본 05 장면에 대한 한국어 음성 인식 검사에서 문장이 일치했다. 해당 발화는 원본 약 2.19–6.19초, 완성본 약 29.19–33.19초다. 별도 [자막 파일](SandGuard-Ending49-v1.srt)을 제공하며 영상에 대사 자막은 굽지 않았다.

음악은 원래 엔딩 자료에 있던 `3.The Eternal Wait.mp3`의 첫 49초를 사용했다. 접촉 실험과 소원 대사 구간에서 음악을 낮추고, 봉인 구간에서 올렸다가 마지막 바람과 점등 소리를 남기며 줄인다. 음악의 특정 마디에 맞춰 전체를 다시 작곡하거나 박자를 재배열한 버전은 아니다.

## 비용

영상 생성은 6+6+6+9+8+8+6=49초, 588크레딧이다. 생성 전 잔액 2,287, 완료 뒤 1,699를 확인했다. 내장 imagegen의 이미지 제작은 이 Higgsfield 크레딧 산정에 포함하지 않는다.

## 영상 검토

- 모든 장면에서 1초 간격의 주요 프레임을 확인했다.
- 04에서 접촉 → 누출 중지 → 손끝의 푸른 변화 → 손을 뗀 뒤 정상 복귀와 누출 재개가 보인다.
- 05의 소원 문장은 음성 인식 결과와 대조했다.
- 06에서 주인공이 푸른 윤곽으로 변하고 사라진 뒤 하늘과 마석이 안정되는 모습을 확인했다. 입자 하나하나의 분해보다는 빛의 윤곽으로 구현되었다.
- 07에서 램프의 작은 점등을 확인했다.
- 최종 재생·크기·길이 검사는 `qa/validation.json`, `qa/decode-check.txt`에 기록한다.

생성 장면 사이에서 램프를 잡는 손의 방향과 소품 크기가 조금 달라진다. 컷 사이 자세 변화로 연결한 첫 편집본이며, 램프의 큰 형태와 문양·주인공의 인상은 유지했다.
