## 이번 사전촬영에 들어간 것

| 구간 | 확인할 연출 |
|---|---|
| 0–9초 | 기둥 옆 이동, 인물의 정지, 마석 균열, 신전과 마을을 보여주는 넓은 시점 |
| 9–12초 | 보호자가 아이를 문 안으로 데려가는 동선 |
| 12–19초 | 오른손 접촉 → 손끝 변화 → 얼굴 반응 → 손 철회와 재앙의 재개 |
| 19–23초 | 옆에서 어깨 뒤로 돌아 올라가며 사막과 마을을 드러내는 이동 |
| 23–28초 | 고정된 얼굴 구도에서 마지막 소원과 짧은 침묵 |
| 28–39초 | 같은 손 구도로 돌아와 결심을 보여주고, 몸을 낮춰 버티기, 역류와 소멸, 마지막 시선 |
| 39–47초 | 램프 낙하를 따라 내려가는 시점, 같은 마을의 회복, 남겨진 램프의 한 번의 점등 |
| 47–49초 | ‘첫 번째 지니’ 제목 |

각 컷에는 별도 카메라와 컷 마커가 있다. 이동 촬영에서는 3D 공간의 가려짐과 원근이 바뀐다. 손 근접 장면은 두 손의 목표 위치를 따로 설정했다. 마력은 방향을 읽을 수 있는 선과 이동 입자로 표시했으며, 마지막 얼굴은 약 1.5초 동안 유지한 뒤 소멸한다.

## 자료 구성

기존 게임에서 주인공의 임시 모델·보행·웅크리는 자세와 램프를 가져왔다. 신전의 촬영 동선, 사막, 마을의 문과 건물, 보호자와 아이, 마력 흐름은 이 사전촬영에 맞춰 배치하거나 새로 만들었다. 사용하지 않는 기존 엔딩 이미지와 이전 생성 영상의 화면은 포함하지 않았다.

대사는 기존 생성본의 “이 사막에 살아가는 모두에게 자유를 돌려줘.” 발화를 임시로 사용했다. 원본 2.0–6.8초를 본편 23.2초에 배치했으며 원본 배경음 일부가 포함된다. 음악은 프로젝트의 `3.The Eternal Wait.mp3` 앞부분을 사용하고 대사 구간의 음량을 낮췄다. 바람·발걸음·균열·공명·낙하음은 타이밍 검토용 합성 효과음이다.

## 현재 단계

카메라와 편집 길이, 이야기의 인과관계를 판단하는 자료다. 게임 모델의 고정 표정을 사용하며 입 모양 연기는 적용하지 않았다. 손가락의 세밀한 파지, 마을 인물의 완성 모델, 의상 시뮬레이션, 연기·모래·빛의 최종 효과와 최종 음향은 후속 제작 범위다. 화면의 컷 번호는 검토용 표기다.

영상 생성 서비스의 추가 크레딧 사용은 **0**이다. 최종 영상 제작이 완료되었다는 의미는 아니다.

## 원본 수정과 재출력

Blender 5.2에서 장면을 열면 1–1176프레임의 컷 마커와 카메라를 확인할 수 있다. 임시 믹스는 오디오 트랙에 들어 있고 텍스처·글꼴·음원은 장면에 포함했다. 3D 카메라 화면은 시퀀서 합성 없이 출력하며, 검토용 컷 이름과 영상 제목의 페이드는 마지막 영상 조립 단계에서 붙인다.

- `build_previs49.py`: 배우·세트·효과·카메라 애니메이션 구성.
- `render_previs49.py`: 음원·제목을 장면에 포함하고 전체 프레임 출력.
- `finish_previs49.py`: 임시 음향 준비, 49초 영상 조립, 전체 디코딩 검사.

출력 검증 후 용량이 큰 중간 프레임 PNG는 정리했다. 영상, 3D 원본, 음향 트랙과 검토 스틸은 보관한다. 다시 영상 조립을 실행하려면 먼저 장면의 전체 프레임을 출력한다.
