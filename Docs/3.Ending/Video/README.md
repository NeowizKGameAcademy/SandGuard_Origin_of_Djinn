# 엔딩 영상 제작 기획 — 첫 번째 지니

현재 기준은 [49초 재촬영안](06_49초_재촬영안.md)이다. v1 영상은 촬영·연기·컷 연결이 요구 품질에 미달해 채택하지 않는다. [레퍼런스 분석과 실패 원인](05_촬영_레퍼런스_분석.md)에 근거를 정리했다. 기존 [49초 제작안](04_49초_제작안.md)과 [production](production/README.md)은 이전 제작 기록이며, 아래 190초 문서는 확장판 참고다.

승인된 [8초 3D 촬영 동선 테스트](production/rework/README.md)를 [49초 전체 사전촬영](production/previs49/README.md)으로 확장했다. 장면 15컷과 제목, 배우 동선·이동 촬영·봉인과 낙하·마을 회복, 임시 대사와 음향을 포함한다. 최종 미술·표정·효과를 적용하기 전의 촬영·편집 검토용이다.

2026-09-22 · 최초 제안 v1 · 3분 10초 / 28컷

**모두를 자유롭게 살게 하기 위해, 자유를 꿈꿨던 한 사람이 램프 안에 남는다.**

기존 엔딩 원문의 핵심을 새 영상 문법으로 각색한 제작 문서다. 기존 컷씬 그림의 구도와 9장 구성을 답습하지 않고, 주인공·램프의 정체성에 필요한 특징만 가져와 인물·공간·소품·효과를 다시 설계했다.

| 문서 | 내용 |
|---|---|
| [01 · 엔딩 영상 시나리오](01_엔딩_영상_시나리오.md) | 28컷 전체. 시간, 화면·행동, 렌즈와 카메라 이동, 조명, 소리, 대사, 전환 |
| [02 · 영상용 자료 설계](02_영상용_자료_설계.md) | 새 인물·배경·소품의 구체적인 모습과 상태, 필요한 시트와 정본 자료, 우선순위 |
| [03 · 컷별 제작 지시서](03_컷별_제작_지시서.md) | 컷의 시작·끝 프레임, 사용할 자료, 복합 장면 분해, 제작 지시문 예시, 편집 연결 |

전투 마무리 22초 → 재앙 38초 → 봉인의 대가 22초 → 마지막 바람 30초 → 소원과 봉인 49초 → 회복과 기다림 29초.

새 각색의 핵심은 **손이 램프에 닿으면 마력이 안정되지만 손끝이 빛으로 풀리고, 손을 떼면 다시 새는 장면**이다. 원작의 ‘영혼이 안에서 힘을 붙들어야 한다’는 설명을 시각적으로 전달한다. 이 연출은 새 제안임을 시나리오에 명시했다.

최초 문서 작업 뒤 v1 이미지·영상 생성과 편집이 이루어졌다. 2026-09-23 사용자의 촬영 품질 지적을 반영해 재촬영 설계로 전환했고, 49초 전체를 실제 3D 카메라와 배우 동선으로 사전촬영했다. 최종 미술·연기·효과를 적용한 완성 영상은 후속 단계다.
