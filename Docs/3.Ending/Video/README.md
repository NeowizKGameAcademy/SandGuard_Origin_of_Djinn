# 엔딩 영상 제작 기획 — 첫 번째 지니

2026-09-22 · 제안 v1 · 3분 10초 / 28컷

**모두를 자유롭게 살게 하기 위해, 자유를 꿈꿨던 한 사람이 램프 안에 남는다.**

기존 엔딩 원문의 핵심을 새 영상 문법으로 각색한 제작 문서다. 기존 컷씬 그림의 구도와 9장 구성을 답습하지 않고, 주인공·램프의 정체성에 필요한 특징만 가져와 인물·공간·소품·효과를 다시 설계했다.

전투 마무리 22초 → 재앙 38초 → 봉인의 대가 22초 → 마지막 바람 30초 → 소원과 봉인 49초 → 회복과 기다림 29초.

새 각색의 핵심은 **손이 램프에 닿으면 마력이 안정되지만 손끝이 빛으로 풀리고, 손을 떼면 다시 새는 장면**이다. 원작의 ‘영혼이 안에서 힘을 붙들어야 한다’는 설명을 시각적으로 전달한다. 이 연출은 새 제안임을 시나리오에 명시했다.

이번 범위는 시나리오·촬영 콘티·제작 지시서다. 새 이미지나 영상, 음성은 생성하지 않았다. 기존 음악은 후보로 기재했으며 실제 음원 고조점에 맞춘 편집은 아직 수행하지 않았다.
