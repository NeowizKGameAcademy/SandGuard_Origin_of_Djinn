## 2. 복합 장면을 제작할 때의 분해

편집상의 28컷은 관객이 보는 장면 단위다. 제작에서는 한 컷을 여러 요소나 짧은 동작으로 나눠 완성할 수 있다. 인물, 카메라, 배경, 마력의 여러 변화를 한 번의 생성이나 렌더에 모두 맡기지 않는다.

| 대상 | 분해할 제작 단위 | 합칠 때 지킬 것 |
|---|---|---|
| 05 | 고정된 마석 표면 / 내부 마력 / 균열 진행 / 파편 떨림 | 균열 시작점과 움직이는 카메라의 시차가 일치해야 함 |
| 07 | 신전·사막 후퇴 카메라 / 지면 오염 / 위쪽 연무 | 오염의 진행 방향과 속도만 증가. 신전이나 마석이 통째로 사라지지 않음 |
| 08~09 | 사람 행동 / 손·팔 오염 / 배경의 바람 | 사람을 바람에 날리지 않고 작은 행동을 선명하게 유지 |
| 12 | A 0~3초 접촉과 안정 / B 3~6초 손끝 연결 / C 6~9초 이탈과 재유출 | 같은 카메라·손·램프. 필요하면 동일 구도에서 이어 붙임. 손끝은 C에서 정상으로 돌아옴 |
| 18 | 소원 대사 연기 / 가슴 앞 램프 / 문양 응답 | 대사 길이를 먼저 확보. 문양의 강한 반응은 말이 끝난 뒤 |
| 20 | 마을의 고정된 구조 / 위로 올라가는 카메라 / 신전 방향으로 빠지는 마력 | 건물·천·인물 행동을 역재생하지 않음 |
| 22 | 안정된 손·램프 자세 / 오른손 소멸 영역 / 빛의 유입 경로 | 왼손과 램프의 형태를 유지. 빛의 목적지는 하나 |
| 23 | 5초의 얼굴 연기와 이동 / 마지막 3초 정지 / 얼굴 소멸 | 눈을 너무 일찍 지우지 않음. 강한 섬광으로 소멸 과정을 덮지 않음 |
| 24 | 인물 없는 신전 / 램프의 짧은 부유와 하강 / 마석 소진 | 램프는 23 직전의 가슴 위치에서 출발하고 같은 상부 바닥에 남음 |
| 26 | 같은 위치의 빈 신전 / 일부 매몰 / 거의 완전 매몰 | 동일한 카메라와 지형. 모래가 누적되는 시간 경과로 연결 |
| 27 | 청동 내부 / 검은 힘 / 인간형 의식 / 짧은 기억 반사 | 의식은 검은 힘과 계속 연결. 기억은 창문이 아님 |

12·19·22·23·27은 서사 이해를 결정하는 장면이다. 간단한 움직임과 임시 효과만으로 먼저 연결해 본 뒤, 정보를 읽을 수 있으면 디테일을 추가한다.

## 3. 움직임 지시문 작성 양식

장면 제작 지시문에는 다음 내용을 이 순서로 적는다. 제작 도구의 특정 모델명이나 최대 길이를 전제하지 않는다.

1. **참조 범위:** 이 컷에 필요한 새 인물·소품·배경 정본의 ID.
2. **시작 상태:** 화면 안의 인물 위치, 램프를 잡은 손, 마력 상태.
3. **행동 순서:** 한 가지 주요 행동과 그 결과. 복합 장면은 초 단위로 나눈다.
4. **카메라:** 렌즈 느낌, 높이, 시작·끝 구도, 이동 한 가지, 멈추는 시점.
5. **환경의 움직임:** 바람, 천, 모래, 오염의 방향과 세기.
6. **끝 상태:** 다음 컷에 연결할 자세·시선·빛의 정도.
7. **연속성 조건:** 바뀌면 안 되는 얼굴, 손, 소품, 공간 기준물.

### 예시 A · 12 ‘손끝으로 알게 된 대가’

> 새 CH-01 손 정본과 PR-01 램프 정본, BG-01의 흐린 배경만 참조한다. 왼손은 둥근 손잡이를 잡고 오른손 끝은 다이아몬드 속 별 문양에 닿기 직전이다. 고정된 100mm 근접 구도에서 손끝과 문양을 같은 초점면에 둔다. 첫 3초에 오른손이 문양을 덮고 램프의 검은 누출이 멈춘다. 다음 3초에는 노출된 손끝 일부가 푸른 입자로 풀려 문양 안으로 이어진다. 마지막 3초에 주인공이 손을 떼면 손끝이 다시 온전해지고 검은 누출이 재개된다. 램프 몸체와 손잡이는 움직임 중에도 단단한 형태를 유지한다. 문양을 가리는 큰 광원이나 카메라 회전 없이 세 상태의 차이를 보여준다. 끝은 램프 옆에 멈춘 온전한 오른손과 다시 새는 얇은 검은 흐름이다.

### 예시 B · 15 ‘가지 못한 곳’

> 새 CH-01 후면, PR-01 램프, BG-04 밤의 틈 상태를 참조한다. 주인공은 화면 아래 왼쪽에 작게 서 있고 왼손에 램프를 내리고 있다. 낮은 난간 너머로 깊이가 다른 세 겹의 모래언덕과 먼 지평선이 펼쳐진다. 지평선 아래쪽에는 계속 움직이는 검붉은 오염, 머리 위 폭풍의 좁은 틈에는 은하수가 보인다. 28mm 넓은 시야로 등 뒤에서 6초 동안 약 1m 상승하고 나머지 4초는 멈춘다. 주인공은 고개를 크게 움직이지 않고 지평선을 바라본다. 붉은 스카프와 얇은 모래만 같은 바람 방향으로 흐른다. 별빛은 사막의 윤곽을 조용히 드러내며 재앙의 빛을 완전히 없애지 않는다. 끝은 작은 사람보다 훨씬 넓게 남는 사막이다.

### 예시 C · 23 ‘마지막으로 남긴 시선’

> 새 CH-01 마지막 시선 표정과 소멸 상태, BG-04의 얕게 흐린 사막을 참조한다. 시작은 사막을 보는 주인공의 옆얼굴과 어깨이며 얼굴과 눈은 온전하다. 75mm 느낌으로 5초 동안 정면 쪽으로 15도만 이동한다. 주인공은 더 오래 하늘을 보고 싶다는 듯 턱을 아주 조금 올린다. 빛의 변화는 아래 몸과 스카프에서 얼굴 쪽으로 진행한다. 이동이 멈춘 뒤 마지막 3초에 얼굴이 얇은 푸른 윤곽으로 바뀌고 눈가의 빛이 마지막으로 남았다가 사라진다. 입자를 화면 밖으로 폭발시키지 않고 램프가 있는 화면 아래쪽으로 이어 준다. 카메라와 지평선은 기울이지 않는다. 끝에는 인물이 있던 자리에 사막의 흐린 배경만 남는다.

| 24 → 25 | 빈자리의 정지 → 움직이는 일상 | 조용한 바람에서 다음 날의 생활음 |
| 26 → 27 → 28 | 밤의 어둠 → 내부 의식 → 외부 문양 | 바람을 먹먹하게 했다가 다시 밖으로 |

대부분의 전환은 단순한 컷으로 한다. 밝은 마법 전환은 원인과 결과를 가릴 때 사용하지 않는다. 시간의 도약이 있는 26과 최종 제목 전환에서만 분명한 겹침·암전을 사용한다.

## 5. 카메라와 사운드 전달표

- 일반 인물 동작은 24fps의 자연스러운 속도다. 감정 장면을 모두 느린 화면으로 바꾸지 않는다.
- 후퇴·상승·옆 이동은 완만하게 시작하고 끝난다. 07의 큰 후퇴 외에는 화면을 휘도는 드론 동작을 쓰지 않는다.
- 12·19의 램프 문양, 21·22의 손, 23의 눈은 최우선 초점 대상이다. 어두운 장면에서도 형태를 읽을 수 있게 한다.
- 각 컷의 편집 길이 외에 앞뒤로 약 0.5~1초의 여유 동작을 확보하면 좋다. 도구가 그 길이를 지원하지 않으면 앞뒤 구도를 별도로 확보한다. 타임코드에 여유 구간을 중복 더하지 않는다.
- 음악, 대사·독백, 생활·환경음, 마력 효과음은 조정 가능한 별도 소리 묶음으로 전달한다.
- 대사 한 문장과 독백 세 문장은 영상 타이밍을 무리하게 늘이지 않는 자연스러운 속도로 녹음한다. 첫 조립본에서 실제 발화 길이에 맞춰 각 컷 안의 시작점을 조정한다.
- ‘마력 흡수’와 ‘영혼이 붙들어 안정됨’은 다른 음색으로 구분한다. 관객이 소리만으로도 11의 실패와 19의 성공을 구별할 수 있어야 한다.

## 6. 제작 순서와 검토 기준

1. **정체성 정본:** 주인공과 램프, 손의 조합을 확정한다. 기존 그림의 구도를 복제하는 대신 새 각도에서 동일성이 유지되는지 본다.
2. **공간 정본:** 신전 상부와 마지막 사막의 관계를 잡는다. 03·15·24에서 같은 지형인지 확인한다.
3. **핵심 시험:** 12 → 13 → 19 → 22 → 23 → 24 → 27을 간단한 임시 영상으로 연결한다. 봉인 원리와 희생이 이해되는지 확인한다.
4. **감정 구간:** 14~18을 붙여 대사 없이도 여행에 대한 갈망과 선택이 읽히는지 확인한다. 독백은 필요한 정보만 보탠다.
5. **재앙과 회복:** 08·09·10·20·21·25를 만든다. 동일 인물과 장소가 회복되는 구조를 유지한다.
6. **전체 조립:** 전투의 마무리, 폭주 전경, 시간 경과와 제목을 붙이고 190초 기준으로 편집한다.
7. **최종 소리:** 기존 음악을 청취해 맞는 구간을 선택하고 필요하면 편집한다. 소원·마지막 숨·램프 착지 소리가 묻히지 않도록 조정한다.

완료 검토에서는 프레임 사이 손가락·램프 형태의 변화, 마석의 상태, 인물의 이동 방향, 12와 19의 차이, 램프가 남는 위치, 재앙의 회수 방향을 우선 확인한다. 같은 정보를 전달하는 전경을 늘려 길이를 채우지 않는다.
