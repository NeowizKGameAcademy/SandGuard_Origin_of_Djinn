# 숨겨진 협곡의 피라미드

좁고 굽은 협곡을 지나 피라미드가 있는 분지로 들어가는 편집 가능한 레벨 초안입니다.

## 열기

Unity 메뉴 **Tools > Desert Tower > Open Hidden Pyramid Canyon**을 선택합니다. 새 씬과 프로젝트의 Level Editor 창이 열립니다. 직접 열려면 `Scenes/HiddenPyramidCanyon.unity`를 더블클릭합니다.

Game 뷰는 전체 전경을 보여 줍니다. Hierarchy의 `View - narrow entrance`, `View - pyramid reveal`, `View - top plan`을 선택하면 카메라 미리보기로 다른 구도를 볼 수 있습니다.

## 구성과 편집

- `Hidden Pyramid Canyon` 아래에서 절벽, 모래 바닥, 피라미드, 돌, 식물을 각각 선택해 편집합니다. 절벽은 개별 오브젝트이므로 이동·회전·크기 변경이 가능합니다.
- 피라미드 내부 진입과 워프는 없습니다. 적은 협곡에서 들어와 외부 나선 경사로를 따라 정상으로 올라갑니다. 플레이어의 수직 이동을 위한 기존 층간 구조를 유지했습니다. 이 씬이 플레이어 이동 능력 자체를 구현하지는 않습니다.
- Level Editor용 적 스폰, 플레이어 시작점, 복귀 지점, 코어, 적 경로와 건설 슬롯 8개를 등록했습니다.
- 지형이나 경사로를 옮겼다면 Level Editor에서 내비게이션을 다시 굽고 경로를 검증합니다. 동선 확인용 6마리 웨이브가 연결되어 있습니다. 실제 전투용 적과 웨이브 밸런스는 별도 설정이 필요합니다.
- 슬롯별 허용 시설 ID는 비어 있습니다. 실제 시설 목록에 맞게 지정해야 건설할 수 있습니다.
- 검증 도구의 '적 진입로는 2개' 경고는 기존 공통 기준입니다. 이 초안은 협곡 입구 하나를 사용합니다.
- `Data/HiddenCanyonLayout.asset`은 배치 데이터입니다. 절벽과 지형까지 보려면 씬을 여세요.

**Rebuild Hidden Pyramid Canyon**은 생성된 씬을 다시 작성합니다. 수작업 편집을 보존하려면 먼저 씬을 다른 이름으로 저장하세요.

## 확인한 사항

생성 시 협곡 스폰에서 정상까지 NavMesh 경로 연결, 레벨 검증 오류 0개, 슬롯 8개, 입구에서 코어 가림 및 분지 안쪽 전경에서 코어 노출을 확인했습니다. 완성된 전투 플레이 테스트를 의미하지는 않습니다.

프로젝트의 `Docs/LevelArt/HiddenCanyon`에 전체 전경, 입구, 피라미드 전경, 평면도 이미지를 저장했습니다.
