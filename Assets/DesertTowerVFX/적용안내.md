# Desert Tower 메인 화면 파티클

원본 메인 화면의 황금빛 모래폭풍과 탑 꼭대기의 청록색 크리스탈에 맞춰 제작한 우선 적용용 3종입니다.

| 파일 | 용도 | 제공하는 UI 애니메이션 |
|---|---|---|
| Textures/SandPuff.png | 황금빛 모래 먼지 | 화면 하단에서 왼쪽→오른쪽 이동, 서서히 커지며 사라짐 |
| Textures/SandstoneShard.png | 각진 사암 조각 | 화면 양옆에서 천천히 떠오르며 회전 |
| Textures/CrystalMote.png | 청록색 빛 입자 | 탑 꼭대기 주변에서 떠오르며 반짝임 |

PNG는 각각 1254×1254의 실제 알파 채널을 가진 단일 이미지입니다. 12프레임 시퀀스가 아니라, 단일 이미지를 이동·회전·확대·페이드하여 반복하는 방식입니다. 크리스탈 본체와 배경 구름을 교체하거나 움직이는 구성은 이번 묶음에 포함하지 않았습니다.

## 가장 빠른 적용: Canvas 메인 화면

Unity UI(uGUI)의 Image/RawImage로 배경을 표시하는 화면용입니다. UI Toolkit 전용 화면에는 이 스크립트를 그대로 붙일 수 없습니다. Unity 2022.3/Unity 6 계열의 uGUI API를 기준으로 작성했으며, 이 환경에서 Unity 에디터 컴파일·실행 검증은 수행하지 못했습니다.

1. ZIP을 풀고 **DesertTowerVFX 폴더 전체를 프로젝트의 Assets 바로 아래**에 복사합니다. `Assets/DesertTowerVFX/Runtime`, `Editor`, `Textures` 구조를 유지하세요.
2. 컴파일이 끝나면 Hierarchy에서 **MainScene.png를 표시하는 배경 Image 또는 RawImage**를 선택합니다.
3. 상단 **Tools → Desert Tower → Add VFX To Selected Background**를 누릅니다.
4. Play를 누르면 모래 12개, 돌 7개, 빛 9개가 반복됩니다. 씬을 저장하세요. Edit 모드에서는 입자가 생성되지 않습니다.

추가된 DesertMenuVFX는 배경의 자식이며, 배경 내부에 버튼 자식이 있다면 그보다 앞쪽 순서로 삽입됩니다. 별도 버튼 패널은 같은 Canvas에서 배경보다 아래쪽 순서에 두세요. 효과 RawImage들의 Raycast Target은 꺼져 있어 클릭을 가로채지 않습니다. 효과 전체는 배경 영역으로 잘립니다. 같은 배경에 메뉴를 여러 번 실행하면 효과가 중복 추가되므로 한 번만 실행하세요. 실행 직후 Ctrl+Z로 추가를 취소할 수 있습니다.

기본 UI 머티리얼로 표시하므로 별도 파티클 셰이더는 필요 없습니다. Screen Space - Overlay에서도 사용할 수 있게 구성했습니다. 제공 스크립트는 Unity Particle System 컴포넌트 대신 UI 이미지들을 애니메이션합니다.

## 위치와 강도 조절

DesertMenuVFX를 선택하고 Inspector에서 아래 값을 조절합니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| Intensity | 0.65 | 전체 투명도. 은은하게 하려면 0.35~0.5 |
| Speed | 1 | 이동 속도. 0은 정지, 0.5는 느리게 |
| Crystal Position | X 0.695 / Y 0.75 | 배경 왼쪽 아래가 (0,0), 오른쪽 위가 (1,1) |
| Sand Count | 12 | 모래 개수 |
| Rock Count | 7 | 돌 개수 |
| Light Count | 9 | 빛 개수 |

개수 및 텍스처 변경은 Play를 종료하고 수정한 뒤 다시 실행하세요. Intensity, Speed, Crystal Position은 실행 중 조절할 수 있지만 Play 중 변경사항은 종료 시 되돌아갑니다. `Time.timeScale = 0`이어도 움직입니다. 효과를 숨기려면 DesertMenuVFX 게임 오브젝트를 비활성화하세요.

모바일 시작값은 모래 6 / 돌 4 / 빛 5를 권장합니다. 이는 실측 성능 수치가 아니며, 실제 기기에서 확인하세요. 개별 UI 이미지와 투명 겹침에 렌더링 비용이 발생합니다.

**배경 이미지와 배경 RectTransform의 영역이 일치해야 크리스탈 위치가 맞습니다.** Image의 Preserve Aspect로 생긴 내부 여백이나 RawImage의 잘린 UV 영역은 자동 보정하지 않습니다. 이미지 비율에 맞는 별도 배경 영역을 만들거나 Crystal Position을 조절하세요. 제공 원본은 약 16:9입니다. Canvas Scaler는 Scale With Screen Size, 기준 1920×1080으로 시작하면 편합니다.

## PNG를 일반 Particle System에서 사용하기

이미 3D/2D 월드 공간 Particle System이 있는 프로젝트라면 Textures의 PNG만 사용해도 됩니다.

1. PNG 임포트 설정은 Texture Type **Default**, Alpha Source **Input Texture Alpha**, **Alpha Is Transparency 켜기**, Wrap Mode **Clamp**, Filter Mode **Bilinear**로 설정합니다. 동봉 Editor 스크립트는 정해진 폴더의 PNG에 이를 자동 적용합니다. Mip Maps는 끄고, 런타임 최대 해상도는 1024로 설정합니다. 원본 파일은 유지됩니다.
2. 효과별 Material을 만들고, 프로젝트 렌더 파이프라인에 맞는 투명 파티클 셰이더를 선택합니다. Built-in은 `Particles/Standard Unlit`, URP는 `Universal Render Pipeline/Particles/Unlit`을 사용할 수 있습니다. 패키지 버전에 따라 항목명이 다를 수 있습니다.
3. 텍스처 슬롯(Base Map/Albedo)에 PNG를 넣습니다. 모래·돌은 Alpha/Fade 블렌딩으로 시작하고, 빛은 Additive 블렌딩으로 시작합니다. 셰이더가 분홍색이면 현재 렌더 파이프라인에 맞는 셰이더로 교체하세요.
4. Particle System의 Renderer → Material에 연결하고 Render Mode를 Billboard로 설정합니다. 단일 PNG이므로 Texture Sheet Animation은 끕니다.
5. Looping을 켜고 Color over Lifetime의 알파를 시작 0 → 중간 1 → 끝 0으로 설정합니다.

시작값: 모래 Lifetime 9~16초, Emission 1개/초, Start Color 알파 약 0.15. 돌 Lifetime 7~12초, Emission 0.7개/초, 약한 Rotation over Lifetime. 빛 Lifetime 2.5~5초, Emission 2개/초. 크기·속도·Shape 영역은 월드 단위와 카메라에 맞춰 조절해야 합니다. UI 스크립트의 정규화 좌표를 월드 좌표로 그대로 넣지 마세요.

일반 Particle System은 Screen Space - Overlay 배경 뒤로 가려질 수 있습니다. Canvas 배경에 효과를 얹는 목적이라면 위의 자동 배치 방식을 사용하세요. 월드 파티클 방식은 카메라, Sorting Layer와 Canvas 렌더 모드를 함께 설계해야 합니다.

## 확인한 내용과 범위

- 배포 PNG 3개의 크기와 실제 알파 채널을 확인했습니다. 바둑판 배경이 구워진 재생성본은 배포에서 제외했습니다.
- 에셋 경로, 자동 배치 로직, 페이드와 입력 차단 설정을 코드 검토했습니다.
- Unity 에디터에서 컴파일·재생·빌드하거나 사용자 프로젝트를 수정하지 않았습니다. 실제 씬의 비율과 UI 계층에 따른 위치 조절이 필요할 수 있습니다.
- 이미지 생성은 내장 image_gen 도구를 사용했습니다. 생성 프롬프트는 생성기록.txt에 동봉했습니다.
