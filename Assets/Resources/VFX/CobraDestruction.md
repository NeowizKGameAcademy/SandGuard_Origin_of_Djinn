# 코브라 타워 파괴

프리팹: `Prefabs/VFX_Cobra_Destruction.prefab`

`Assets/2.Model/Prefabs/Tower (Cobra).prefab`의 보이는 메시를 분할하고 원본 UV와 머티리얼을 유지한다. 숨겨진 사거리 표시는 파편에 포함하지 않는다. 원본 프리팹은 수정하지 않는다.

- 0~0.08초: 원래 모습의 대체 메시 유지.
- 0.08초: 짧은 주황·백색 섬광과 작은 모래 충격파, 파편 방출.
- 약 1.1초까지: 코브라 파편이 짧게 퍼지고 회전하며 바닥에 내려앉음.
- 약 1.5초: 불씨와 모래 먼지가 사라지고 어두워진 금속·석재 파편만 남음.

## 연결

코브라 루트와 같은 위치·회전·스케일에 생성하고 `VfxCobraDestruction.BindTarget(tower.transform)`을 호출한다. VFX를 코브라 자식으로 붙여도 자신의 렌더러는 숨기지 않는다. 원본 렌더러와 조명을 숨기고 원본 파티클을 정지한다. 타워의 공격·충돌·체력·사망 판정은 게임 코드에서 처리해야 한다.

이펙트를 반환해도 원본은 다시 나타나지 않는다. 전시 반복이나 리스폰에서만 `RestoreTarget()`을 명시적으로 호출한다. 같은 타워에 중복 바인딩하지 않는다. VFX는 약 3초 뒤 반환하면 되며 그때 잔해도 제거된다.

파편은 평평한 바닥 y=0을 기준으로 정해진 궤적을 사용하며 실제 벽·경사면과 충돌하지 않는다. 원본 메시의 삼각형을 구역별로 나눈 시각 파편이며 절단면을 막는 물리 절단은 아니다. 타워와 별도인 받침대는 제거하지 않는다.
