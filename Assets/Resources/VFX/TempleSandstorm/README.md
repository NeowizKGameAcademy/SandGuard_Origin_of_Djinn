# 신전 봉인 모래폭풍 시안

## 보기

- 씬: `Level_Sandstorm.unity` — 원본 `Assets/1.Scene/Level.unity`를 복사한 별도 프리뷰.
- 프리팹: `VFX_TempleSandstorm.prefab` — 다른 씬에도 독립 배치 가능.
- 씬을 열고 Play 하면 모래층의 흐름과 입자를 볼 수 있다.
- `Preview - Overview`가 기본 전경 카메라다. `Preview - Vertical Top`, `Preview - Inside Temple`은 비활성 카메라이며 선택하면 카메라 미리보기로 구도를 볼 수 있다.
- 실제 촬영 결과: `Docs/LevelArt/TempleSandstorm/`.

## 구성

- 노이즈가 흐르는 고리 메시 3겹. 안쪽 반경 약 130m, 바깥 반경 최대 204m, 최고 높이 약 100m.
- 지면 먼지 파티클 1개, 청록빛 봉인 입자 파티클 1개.
- 중앙 전투 공간은 비워 두었다. 충돌체, 데미지, 이동 차단, 내비게이션 변경은 없다.
- 실제 유체/체적 시뮬레이션이 아닌 투명 메시와 파티클을 조합한 시각 프로토타입이다. 성능 실측과 최종 아트 튜닝은 아직 하지 않았다.
- 원본 씬과 원본 공유 프리팹은 수정하지 않았다. 복사본에서는 촬영용 카메라를 추가하고, 원래 카메라를 비활성화했다. 저고도 구름, 하늘 돔/별 장식, 사거리 표시 렌더러를 복사본에서 숨겼다. 바닥은 기존 평면을 유지한다.

## 조정

- `TempleSandstorm.animationSpeed`: 전체 모래 흐름 속도.
- `animate`를 끄고 `previewTime` 변경: 특정 모래 패턴 시점 확인.
- `M_StormBody_0~2`: Density, Flow Speed, Shadow Sand, Sunlit Sand 조정.
- 입자 개수/크기/회전은 프리팹 자식 `Ground sweeping dust`, `Seal embers`의 Particle System에서 조정.
- 기본 크기는 이 Level 신전을 기준으로 제작했다. 프리팹 스케일로 다른 크기의 신전에 맞출 수 있으나, 속도·카메라 가독성은 다시 확인해야 한다.

## 검증

- Unity 6000.2.8f1 / URP 17.2에서 생성·저장 및 실제 카메라 렌더.
- 메시의 비정상 좌표 검사, 셰이더 컴파일 오류 검사.
- 전경/수직 탑뷰/신전 내부 3개 구도 촬영.
- 같은 카메라에서 서로 다른 셰이더 시간으로 촬영해 무늬 변화 확인.
- 전투/프레임 속도 검증은 포함하지 않는다.

빌더 메뉴는 기존 프리뷰 씬을 덮어쓰지 않는다. 수작업 편집 후 자동 재생성하지 말 것.
